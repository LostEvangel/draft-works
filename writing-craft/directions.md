# 写作方向与能力分层

目录名用英文；对话与文件标题用中文展示名。

## 能力分层

| 目录名 (id) | 展示名 | 生效范围 |
|-------------|--------|----------|
| `core` | 核心底盘 | **全场景**：观点边界、通用禁忌、优化底线 |
| `lyrical` | 抒情 | 仅抒情向优化时 |
| `argumentative` | 议论 | 仅议论向优化时 |
| `narrative` | 叙事 | 仅叙事向优化时 |
| `expository` | 说明 | 仅说明向优化时 |

优化草稿时：**先加载 `core`，再加载用户确认的方向目录。**

## 方向侧重

| 目录名 | 展示名 | 侧重 |
|--------|--------|------|
| `lyrical` | 抒情 | 情绪、意象、感官、语气与余韵 |
| `argumentative` | 议论 | 论点、论据、反驳、逻辑递进 |
| `narrative` | 叙事 | 场景、人物、时间线、细节与节奏 |
| `expository` | 说明 | 概念澄清、层次、读者前提、信息密度 |

## 推荐规则

1. 通读草稿后，从四个写作方向中选出最贴切的 2～3 个（`core` 不参与推荐，始终生效）。
2. 说明推荐理由（各一句），请用户确认或改选。
3. 用户可增删方向；确认后再写 `suggestions/`。

## 沉淀分层

- 全场景都成立的禁令/底线 → `capabilities/core/`
- 仅某方向成立 → 对应方向目录
- 负面优先：先写「禁止 X」，再写「要求 Y」

## 扩展

若需新方向：在本表增加一行，并在 `capabilities/` 下新建同名空目录。
