# 能力规则写法

把「感觉不对」写成 AI 能执行的硬规则。

## 公式

```
规则 = 适用范围 + 明确指令（禁止 / 要求）+ 触发场景 + 优先级
```

| 字段 | 要求 |
|------|------|
| 适用范围 | `core` 或某一方向目录 |
| 指令 | 必须是「禁止 X」或「要求 Y」，禁止「注意保持…」「尽量…」 |
| 触发场景 | 何时生效（如：处理结尾时 / 出现第一人称时） |
| 优先级 | `high` 违反即失败；`medium` 影响风格；`low` 优化建议 |

## 对错对照

❌「要注意口语化」「不要太书面」「尽量保留风格」  
✅「禁止把『我觉得』统一改成『笔者认为』」  
✅「禁止把具象行为描写替换为抽象情绪概括」  
✅「要求保留原文开放式结尾，不得自行加升华句」

## 入库前检查

- [ ] 适用范围明确（core / 方向）
- [ ] 指令是祈使句，无模糊词
- [ ] 有触发场景
- [ ] 优先级合理
- [ ] 不与已有规则重复或冲突
- [ ] 念一遍：AI 看了知道做什么吗？

## 迭代原则

- 负面优先：先禁令，后正面要求
- 宁细勿粗
- 多次出现的临时要求，再升级为正式能力
